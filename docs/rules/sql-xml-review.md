# SQL、MyBatis 与 XML 审查规则

审查 SQL、MyBatis 映射和相关 XML 时，只报告输入里能直接核对的问题。不把某个数据库供应商的方言、备份命令、目录或功能号例外当成固定规则。未知方言行为不报中高风险。

- 常规参数使用绑定参数，例如 MyBatis `#{ }`。`${ }`、字符串拼接 SQL、动态表名或排序字段，必须有白名单和可信来源，否则按注入报告。
- `SELECT` 显式列出字段。`INSERT` 显式列出目标列。
- `DELETE` 和 `UPDATE` 必须有可验证的范围条件。无条件全表更新或删除，在能定位到语句时按高影响数据错误报告。
- 检查字段类型、默认值、非空、返回映射，以及 Schema、XML 和代码之间的字段是否一致。
- XML 映射和配置要能解析：标签闭合、参数名与代码属性一致、结果映射没有明显错列。
- 分页和事务只在语句或调用处有证据时检查是否缺失或范围错误。
- 复杂 SQL 的性能问题需要查询规模、索引或调用频率证据。没有这些证据就不报中高风险性能问题。
