# Python 审查规则

审查 Python 源码时，重点检查以下通用高价值问题：

- 可变默认参数、闭包晚绑定、意外的全局可变状态
- 异常吞没、裸 `except`、资源未用 `with` 关闭
- 类型与空值误用：未校验的 `None`、错误的 `isinstance`/`hasattr`
- 并发：`threading`/`asyncio` 竞态、未 await 的协程、事件循环阻塞
- 注入：SQL/命令/路径拼接、未转义的 `eval`/`exec`/`pickle`
- 输入边界：未校验长度/类型的外部数据、路径穿越
- 依赖与导入副作用、循环导入导致的半初始化
- 数值精度与时间时区处理

仅基于本次输入中的证据报告问题，不引入未在输入中出现的内部约定。
