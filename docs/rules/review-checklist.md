# 审查检查清单

对匹配文件逐项核对：

## 并发

- 共享可变状态是否有同步或明确的无竞争设计
- 是否存在死锁、活锁或错误的锁粒度

## 内存边界

- 缓冲区、数组、集合访问是否越界
- 分配大小与实际使用长度是否一致

## 外部输入

- 来自网络、文件、用户或配置的输入是否做长度与格式校验
- 不可信数据是否直接用于控制路径、命令或查询

## 错误处理

- 错误返回值、异常是否被检查并正确传播
- 是否存在吞掉错误后继续错误状态的路径

## 资源生命周期

- 打开的文件、句柄、连接、锁是否在所有路径上释放
- 所有权转移是否清晰，避免泄漏与重复释放

## 控制流

- 条件、循环、早期返回是否覆盖边界与失败分支
- 是否存在不可达逻辑或遗漏的默认分支
