# 示例项目需求说明

## 功能概述

对用户提供的一段文本进行规范化处理，供下游模块消费。

## 输入约定

| 项 | 说明 |
|----|------|
| 类型 | UTF-8 字符串 |
| 来源 | 标准输入、配置文件或 API 请求体中的 `text` 字段 |
| 约束 | 最大长度 4096 字符；允许 `null` 或仅空白（视为空输入） |

## 输出约定

| 项 | 说明 |
|----|------|
| 类型 | UTF-8 字符串 |
| 格式 | 去除首尾空白后转为小写；空输入输出 `""` |
| 示例 | 输入 `"  Hello World  "` → 输出 `"hello world"` |
| 错误 | 非法编码或超长输入应返回明确错误码，不得静默截断 |

## 非功能要求

- C++ 实现（`demo.cpp`）与 Java 实现（`Demo.java`）行为语义一致。
- 不得在未校验指针/引用的情况下解引用可能为空的对象。

## 验收标准

1. 上述输入输出用例通过。
2. 对 `null`、空串、纯空白输入均返回 `""`。
3. 代码审查报告中应能识别明显的空指针或未定义行为风险（若存在）。
